### About

- Two tracks, and they meet in the middle: **game development** on the client and **backend &amp; infrastructure** behind it. Multiplayer, live content and telemetry need both, so I keep both sharp.
- **Games** — Unity and C# for PC, mobile and VR: gameplay systems, tooling for designers, and the performance budget that keeps it all at frame rate.
- **Backend** — Go, Python and .NET services, bots and APIs, with PostgreSQL and Redis underneath.
- **Infrastructure** — I ship what I write: Docker, Linux, nginx, CI, and the VPS it all lives on.
